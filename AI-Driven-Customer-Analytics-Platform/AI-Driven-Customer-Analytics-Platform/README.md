# AI-DRIVEN CUSTOMER ANALYTICS PLATFORM

This platform performs customer segmentation using K-Means clustering and predicts total customer spending using a Random Forest Regressor. It includes an interactive Streamlit dashboard for real-time predictions.

## Project Structure
- `app.py`: Streamlit application code.
- `rf_reg_model.pkl`: Trained Random Forest model.
- `scaler.pkl`: StandardScaler used for feature normalization.
- `customer_segments.csv`: Processed dataset with cluster labels.
- `requirements.txt`: List of dependencies.
